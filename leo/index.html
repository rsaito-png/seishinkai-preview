レオ

情緒を整え、落ち着きを取り戻すことを目指します

日常生活に必要な動作の指導をしたり、人や物を通して情緒の安定を丁寧に図ります。

落ち着きがない、こだわりが強い、集団が苦手なお子さま。医師の診断の有無は問いません。お子さま一人ひとりの安心できる居場所を作ります。

※地域によって送迎のご相談も承ります。

FEATURES

レオの療育の特徴

好きを見つけ、チャレンジする

たくさんのおもちゃの中から自分の好きなものを見つけたり、スタッフと一緒に少し難しい課題にも挑戦。「認知・行動」「言語・コミュニケーション」「社会性」を育みます。

武道・ヨガ・農作業で心身を鍛える

格闘家や農家さんのもとへ赴く地域連携を実施。「健康・生活」「運動・感覚」を刺激し、身体を動かす楽しさと情緒の安定を両立させます。

自然観察とアウトドア体験

菰野町のフィールドにお出かけして、遊びながら自然観察をしたり、七輪で火起こしに挑戦。五感を使った本物の体験を大切にしています。

家族支援・進路相談（移行支援）

経験豊富な専門スタッフが保護者の方の相談に寄り添い、職員の指導力向上にも尽力。建物の2階、看板のあるドアから気軽にお入りいただけます。

🍱 手作りの和定食で情緒を養う（1回 300円）

レオでは温かい手作りの昼食を提供しています。食事を通じて心を落ち着かせ、偏食の改善指導にも丁寧に取り組んでいます。

HOW TO START

利用開始までの流れ

  1. 問い合わせ　電話（070-6967-0011）またはLINEでご連絡ください。
  2. 見学　お子さまと一緒に教室の様子をご覧ください。
  3. 受給者証の申請　お住まいの市町で通所受給者証を申請します。四日市市はこども発達支援課（059-354-8064）、菰野町は子ども家庭課 発達支援係（059-391-1226）です。詳しくは受給者証ガイドへ。
  4. 契約　受給者証が届いたら、レオと利用契約を結びます。
  5. 利用開始　個別支援計画にそって通所を始めます。

手続きでわからないことは、こちらで案内します。

EVALUATION

令和7年度 事業所評価（児童発達支援）の要点

保護者評価（対象11名・回答10名、2026年2月実施）と従業者評価（対象4名・回答3名）をもとにまとめた総括表の要点です。

強み

  • 体験型プログラムの多様性（茶道、畑、料理など）。季節に応じたイベントや、家庭では経験しにくい活動を取り入れています。
  • LINEによる高頻度・詳細な活動報告。毎回、活動の様子を写真と文章で共有しています。
  • 専門性の高い個別支援と共感的な姿勢。職員一人ひとりがこどもの特性を理解し、寄り添った支援を行っています。

課題と改善の取り組み

  • 業務継続計画（BCP）の浸透：具体的な場面を想定したロールプレイング研修を行い、役割分担を掲示します。
  • 非常災害訓練・安全計画の周知：訓練の様子をLINEで配信・掲示し、安全計画をあらためて配布します。
  • 地域交流の機会：近隣の公園や図書館などの利用を再開し、地域行事への参加を計画します。

放課後等デイサービスの評価と各評価表の全文は、このページの「令和7年度 事業所評価の公表」のPDFでご覧いただけます。

FAQ

よくある質問

対象は何歳ですか？

満1歳から18歳までです。小学校入学前は児童発達支援、小学生以降は放課後等デイサービスとして利用します。

診断がないと利用できませんか？

診断の有無は問いません。今の困りごとから始めます。

費用はいくらですか？

公的制度（通所受給者証）を使います。所得に応じた負担上限があり、満3歳になって初めての4月1日から小学校入学前の3年間は、国の制度で利用者負担が無償です。昼食は1回300円です。手続きは受給者証ガイドをご覧ください。

利用時間は？

1部が11:00〜14:30、2部が放課後〜17:00です。

送迎はありますか？

地域によって相談を受けます。お問い合わせの際にお住まいの地域をお知らせください。
